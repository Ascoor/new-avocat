# Documentation index

This repository ships documentation by area so you can quickly locate the right guide:

- `backend/` – Laravel API setup, maintenance, and troubleshooting.
- `frontend/` – React/Vite SPA notes and API integration tips.
- `scripts/` – Utility tooling (dashboard generator, dev orchestrator) lives in `../scripts/` but is documented from the code itself.

If you add new guides, prefer placing them alongside their domain (e.g., `docs/backend/`) and link them back here.
